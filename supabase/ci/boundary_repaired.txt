# asserts it for each.

# Specification v1.2 §16.2: the door and the proof that it is governed land in
# one transaction. A migration that missed the proof and has already been
# pushed cannot gain it in place, because a migration is written once, and the
# grandfathered list (boundary_grandfathered.txt) takes nothing new. So the
# repair is forward: a later migration that calls erp.assert_public_api_safe()
# over the whole schema, the door included.
#
# One line per file: <migration missing the proof> <migration that asserts it>
#
# supabase/ci/boundary_in_migration.sh accepts an entry only when the repairing
# migration exists, sorts after the one it repairs, and itself calls the
# assertion, so a line here cannot silence the check. The window it leaves (the
# door lived unproved from its own deploy to its repair's) is written beside
# each entry.
